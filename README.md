# monasafer-back

API de **Monasafer**: gastos a futuro, reservas y cuánto te va a sobrar a fin de mes.
NestJS + MongoDB. El front está en `monasafer-front`.

```bash
npm ci
npx jest            # motor de cálculo
npm run start:dev   # puerto 3001 (sin MONGO_URI arranca sin base)
```

Documentos del proyecto (backlog, preguntas, infra): [proyecto/](proyecto/README.md).
